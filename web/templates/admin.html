Impostazioni

Sicurezza

Cambia la password dell'account admin. Richiede la password attuale.

Manutenzione

Svuota la cache in memoria (risultati browse/search). I plugin la ripopolano alla richiesta successiva.

Zona pericolosa

Azioni distruttive e irreversibili. Ognuna richiede di reinserire la password admin.

Elimina tutti i profili, la cronologia di visione e i secret per-profilo dei plugin. I dispositivi accoppiati restano.

FLUSHDB su Redis, svuota la cache immagini WebP e i file cache su disco dei plugin. I plugin restano installati e configurati; ricostruiscono le cache alla sincronizzazione successiva.

Cancella tutto: profili, dispositivi accoppiati, dati/cache dei plugin, i plugin stessi e la password admin. Come alla primissima installazione — si torna alla pagina di setup. Irreversibile.

Uscite di rete

Ogni plugin sceglie da quale uscita passa il suo flusso video (scheda Plugin). Diretta = IP del server. Puoi aggiungere proxy SOCKS5/HTTP o configurazioni WireGuard e attivarli/disattivarli senza toccare i plugin.

iOS / macOS

Pileus per iPhone / iPad
Installazione senza App Store
  1. 1. Apri /app/ in Safari.
  2. 2. Tocca Condividi (il quadrato con la freccia in su).
  3. 3. Scorri e tocca "Aggiungi a schermata Home".
  4. 4. Tocca "Aggiungi". L'icona compare sulla Home.
Apri la guida a schermo intero

Una volta installata, l'app parte a schermo intero come un'app nativa. La stessa procedura vale per Mac (Safari → Condividi → Aggiungi al Dock).

App web Pileus

Scarica l'ultimo build web di Pileus dalle GitHub Release del repo configurato e lo installa in data/pileus-web/ (servito su /app). La versione precedente resta in data/pileus-web.bak/.
